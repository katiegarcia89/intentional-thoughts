# Intentional Thoughts ❤️

**Intentional Thoughts** is a personal web project dedicated to celebrating meaningful moments with family through interactive digital experiences.

The first experience, **Happy Father's Day, Pop**, was designed, built, and deployed in less than 24 hours using **Codex** and **Netlify**. Rather than creating a traditional greeting card, the project combines storytelling, animation, music, photography, and personal messages into an interactive web experience.

This repository serves as the foundation for future celebrations, with plans to continue expanding the website for holidays, birthdays, anniversaries, and other meaningful family milestones.

---

## Features

- Interactive multi-page greeting card
- Custom CSS animations and transitions
- Responsive design for desktop and mobile devices
- Embedded Apple Music soundtrack
- Personalized voice recording
- Family photo gallery
- JavaScript-powered page navigation
- Lightweight static website deployed with Netlify

---

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Codex
- Netlify

---

## Project Goals

The purpose of this project is to create memorable digital experiences for family members while continuing to practice front-end development skills.

Future plans include:

- Father's Day enhancements
- Holiday-themed experiences
- Birthday celebrations
- Anniversary pages
- Interactive games and surprises
- Improved animations
- Additional accessibility improvements
